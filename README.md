# Opal CHR Consulting — Landing Page

Site web premium pour **Opal CHR Consulting**, cabinet expert en conseil stratégique pour les Cafés, Hôtels et Restaurants.

## Stack

- HTML5 / CSS3 / JavaScript vanilla
- [GSAP 3.12.5](https://gsap.com/) (animations scroll + hero)
- [Cormorant Garamond](https://fonts.google.com/specimen/Cormorant+Garamond) + [Outfit](https://fonts.google.com/specimen/Outfit) (Google Fonts)
- Aucune dépendance npm — sources CDN uniquement

## Structure

```
opal-chr-consulting/
└── index.html   ← page complète (CSS + JS inline)
```

## Sections

1. **Hero** — Accroche 2 colonnes + mosaïque statistiques
2. **Expertises** — 6 services CHR en grille
3. **Approche** — Méthode data-driven + graphique de performance
4. **Résultats** — KPIs animés + témoignages clients
5. **Contact** — Formulaire d'audit gratuit
